# System wypożyczeń sprzętu

Projekt Komisji Cyfryzacji SSPW na kadencję 2026/2027 dotyczący wypożyczania **istniejącego sprzętu**.

## Cel

Uporządkować proces korzystania z istniejącego sprzętu SSPW. Zakupy nie są warunkiem rozpoczęcia ani realizacji projektu.

## Aktualny stan

Etap ustalania właściciela procesu i inwentaryzacji zasobu.

## Minimalny zakres pierwszego etapu

- wskazać właściciela procesu,
- zinwentaryzować istniejący sprzęt,
- opisać pełny proces: rezerwacja → wydanie → zwrot,
- ustalić role,
- opisać obsługę opóźnień i uszkodzeń.

## Zależności

- opiekun lub właściciel procesu,
- potwierdzona lista istniejącego sprzętu,
- reguły wydawania i odpowiedzialności.

## Następny krok

Ustalić właściciela procesu i wykonać pierwszą inwentaryzację potrzebną do obsługi jednego pełnego scenariusza wypożyczenia.
